Directory for documentation
===================

Supporting documentation for the Federated Payer Identifier prototype. The
core specification documents live at the repository root; this directory holds
additional design proposals and their assets.

## Contents

* [NPD Endpoint Feedback API](npd-how-did-it-go-api.md) — design proposal for
  reporting the outcome of an attempted interoperability exchange back to the
  National Provider and Payer Directory. Either participant reports
  independently; reports record observations without establishing fault.
  * `NPD_Query_Flow.png` — flow diagram used by that document, showing
    discovery, the attempted exchange, and the independent reports.

See the [repository README](../README.md) for this repository's contents. The
root-level specification documents — including
[FPI generation](https://github.com/ftrotter-gov/FederatedPayerIdentifier/blob/main/GeneratingFederatedPayerIdentifiers.md)
and the
[payer well-known index format](https://github.com/ftrotter-gov/FederatedPayerIdentifier/blob/main/WellKnownFileFormat.md)
— remain in the
[Federated Payer Identifier repository](https://github.com/ftrotter-gov/FederatedPayerIdentifier).
